## 背景

按 `.dev/plans/0.3.0-borrow-check-milestones.md §3.0`，M0 baseline 验证的退出准则是「所有 48 个 m0_*.uc 测试通过」。其中：

- m0_07 / m0_38 已划入 M1 范畴（HANDOFF §7 陷阱 #2），不计入 M0 PASS 目标
- M0 真范围 = 48 - 2 = **46 个测试**
- 当前 baseline：**27/48 PASS / 21 FAIL**（P0-1 → P1-1 阶段 commit 后）

## 已完成的 0.3.x 工作

| 版本 | 主题 | spec 文件 | 翻转的 M0 测试 |
|---|---|---|---|
| 0.3.1 | S2 lvalue/rvalue 形式化 | ✅ 已 commit `0f6b606` | m0_42 (deref-assign) |
| 0.3.2 | S4 cast + S5 return-type + §11.0 builtin | ❌ spec 文件未构造 | m0_41 (extern_c abs_int) + 完成 m0_42 |
| 0.3.3 | S1 unary 优先级 + S3 deref + 函数化 | ❌ spec 文件未构造 | m0_36 (move/free) ±m0_34 |

**累加预测**：30/48 PASS（62.5%），**距离 M0 闭合差 16+ FAIL**。

## 决策（Option 1）

**扩展 0.3.x iteration 为 0.3.1 → 0.3.7**，新增 4 轮 spec 迭代覆盖剩余 M0 FAIL：

| 版本 | 主题 | 触发的 m0 测试 | 根因类别 |
|---|---|---|---|
| 0.3.4 | Parser 扩展：array + struct | m0_26, m0_27, m0_28, m0_32, m0_33 | parser 缺 |
| 0.3.5 | Parser 扩展：fn-ptr + #include + multi-file | m0_37, m0_40, m0_44 | parser 缺 / linker |
| 0.3.6 | Runtime：main return code + exit propagation | m0_02, m0_03, m0_08 | runtime |
| 0.3.7 | Runtime：bitwise ops + string | m0_05, m0_06, m0_24, m0_25 | codegen / runtime |
| (verify) | m0_30 / m0_34 / m0_48 | 0.3.3 §4.13.5 + 验证后确定 | 0.3.3 后续 |

**累计预测**：

```
0.3.1 → 28/48 (+m0_42)
0.3.2 → 29/48 (+m0_41, +完成 m0_42)
0.3.3 → 30/48 (+m0_36, ±m0_34)
0.3.4 → 35/48 (+5 array/struct)
0.3.5 → 38/48 (+3 fn-ptr/include/multi-file)
0.3.6 → 41/48 (+3 main return / exit)
0.3.7 → 45/48 (+4 bitwise / string)
verify → ~46/48 (+m0_30/m0_34/m0_48 视验证结果)
```

**M0 闭合目标**：46/46 → 进入 M1。
