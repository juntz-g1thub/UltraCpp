## §1. 用户决策（4 项硬约束）

0.3.3 实施启动前，orchestrator 与用户对齐 4 项决策：

### D1 — commit 7 拆分为 5 个 sub-commit
**不再**一次性缩减 `BUILTIN_SIGS[]` 14 项到目标 6 项；改为 5 个 sub-commit（**7a / 7b / 7c / 7d / 7e**）渐进清理。
原因：单 commit 重写 builtin 路由表风险高、回退成本大；拆分后每个 sub-commit 都能独立回滚 + 跑 baseline 验证。

### D2 — `abs_int` 永久保留到 0.3.4
当前 inline LLVM IR 实现（`get_builtins_defs()` 中 `define i32 @builtin_abs_int(i32 %x)`）**保留**。
原因：m0_41 测试验证此函数；`lib/math.uc` 还没就绪（in 0.3.3 spec 范畴外）；突然移除会直接 FAIL m0_41 回归 baseline。
实际语义：`abs_int` 的 0.3.4 迁移（到 `lib/math.uc` UltraCPP 实现）等价于 commit **7e**，但推迟到 0.3.4 阶段。

### D3 — `sys::` 与 `sys$` 命名共存
0.3.3 阶段**保留** `sys$`（old, hardcoded in `gen_syscall_call`）+ **新增** `sys::`（per runtime-architecture）作为别名。
原因：最小侵入；现有 `lib/io.uc` 用 `sys$strlen`/`sys$write`，0.3.3 不强行迁移。
实际语义：sys$ → sys:: 完全迁移（统一命名）推迟到 0.3.4 或更后版本。

### D4 — 整体 0.3.3 实施按修订后 **8 + 4 commits** 开工
8 个原始 commits（1-6 + 8） + 4 个 sub-commits（7a-7d） = **12 个 commit** 总数（7e 留 0.3.4）。
原因：原 `.dev/drafts/0.3.3-implementation-plan.md` §"Phase 拆分" 把 commit 7 视为单个 commit，但代码层面需要更细粒度；D1 决策覆盖原计划假设。

## §2. 架构发现（关键 — 与原计划假设的偏差）

原计划 `.dev/drafts/0.3.3-implementation-plan.md` 假设 `lib/uc_runtime.c` 是 C bootstrap，14 项 builtin 在该文件中由 C 实现，src-c 链接时 include 该 .c 文件。
**实测后这一假设错误**：当前 src-c/ 采用 **inline LLVM IR + libc 链接**混合方案，**`lib/uc_runtime.c` 不存在**（`find . -name "uc_runtime*"` 0 命中）。

### §2.1 当前 builtin 机制（src-c/src/codegen.c）

| 组件 | 位置 | 行数 | 作用 |
|---|---|---|---|
| `builtin_sig_t` 类型 | codegen.c:16-19 | 4 | `{name, llvm_ret}` 二元组 |
| `builtin_sigs[]` 表 | codegen.c:20-26 | 7 | **14 项** name + LLVM 返回类型映射 |
| `lookup_builtin_ret()` | codegen.c:27-32 | 6 | 线性查表，返回 LLVM 返回类型字符串 |
| `get_builtins_decls()` | codegen.c:295-302 | 8 | emit `declare i64 @strlen(i8*)` 等 libc 符号声明 |
| `get_builtins_defs()` | codegen.c:310-330 | 21 | **inline LLVM IR 函数体**（`@builtin_abs_int` 完整实现 + 3 个 print stub） |
| `mangle_name`（sys$* 前缀） | codegen.c:259-264 | 6 | `sys$foo` → `@sys$foo` 符号 |
| `gen_syscall_call` | codegen.c:979-1020 | 42 | 处理 `sys$strlen`/`sys$write`/`sys$read` → 直接映射 libc 符号 |

**UCExprCall codegen 主流程**（codegen.c:1313-1345）：
1. 调用方形如 `sys$*` 前缀 → 走 `gen_syscall_call`（直接映射 libc） ✅ **sys$ 不受影响**
2. 否则查 `lookup_builtin_ret(fn_name)` → 若命中重命名 `@builtin_<name>`（body 来自 `get_builtins_defs()` emit 的 inline IR）
3. 否则查 `lookup_extern_func(fn_name)` → 用 extern 声明
4. 否则默认 i32 返回

### §2.2 lib/ 实际状态

```
lib/io.uc   (231 bytes, 9 行)  — UltraCPP 源码，sys$strlen + sys$write 包装
lib/math.uc (51 bytes, 3 行)   — UltraCPP 源码，只有 add 函数，无 abs_int
```

**两个文件均不被 src-c/Makefile 编译**（Makefile 只编 `src/*.c`）。它们是 **0.3.4 阶段**用 UltraCPP 自写 stdlib 的占位。
**`lib/uc_runtime.c` 不存在**——原计划假设失效。0.3.3 实施阶段无需创建此文件。

### §2.3 14 项 builtin 的 3 类分类

| name | 类别 | 0.3.3 处理 |
|---|---|---|
| `print` / `print_num` / `print_float` | inline IR stub (`ret void`) | **7b 移除**（m0 测试不验证输出） |
| `strlen` / `strcpy` / `strcmp` | libc 声明（`declare i64 @strlen(i8*)` 等） | **7d 移除**（`sys$strlen` 走 `gen_syscall_call` 不受影响；直接 `strlen()` 会 link-fail，**但当前 src-c 无直接调用方**） |
| `memcpy` / `memmove` / `memset` | libc 声明但 codegen 不 emit | **7d 移除**（仅作类型查询占位） |
| `sizeof_impl` / `alignof_impl` / `is_null` | intrinsic 包装（0.3.3 §3c 转为 intrinsic 节点） | **7c 移除**（前提：commit 3 intrinsic codegen 已就绪） |
| `clone_impl` | 无 emit 路径（grep 0 命中） | **7b 移除**（移除安全） |
| `abs_int` | inline IR 完整实现 | **7e 永久保留到 0.3.4**（per D2；m0_41 验证此函数） |

### §2.4 m0_41 回归风险确认

m0_41 当前工作链（test/programs/baseline/m0_41_extern_c.uc:6-12）：

```
abs_int(-7) → lookup_builtin_ret("abs_int") 命中（builtin_sigs[] 第 14 项 "abs_int", "i32"）
            → rename 为 @builtin_abs_int
            → get_builtins_defs() 已 emit "define i32 @builtin_abs_int(i32 %x) { ... }"
            → LLVM 链接本地 IR → PASS
```

**若 0.3.3 阶段 commit 7a-7d 误删 `abs_int` entry 且无替代**：
`emit @abs_int(i32 -7)` → LLVM 找不到 `@abs_int` → **m0_41 FAIL** → baseline 27→26。

**缓解**（per D2 + commit 7a-7d 严格不动 abs_int）。

### §2.5 原 plan 与实测差异汇总

| 维度 | 原 plan 假设 | 实测 |
|---|---|---|
| `lib/uc_runtime.c` | 存在，C bootstrap 14 项 builtin | **不存在**（find 0 命中） |
| builtin 实现机制 | C 函数 + 链接 | **inline LLVM IR + libc 声明** |
| `abs_int` 迁移时机 | 0.3.3 迁到 `lib/math.uc` UltraCPP 版 | **推迟到 0.3.4**（per D2） |
| 14 项 builtin 总数 | 同步全迁到 `lib/*.uc` | 0.3.3 缩到 8 项 (`alloc`/`free`/`move`/`clone`/`mod`/`unmod` + 2 保留)，`abs_int` 保留 → 0.3.4 最终 6 项 |
| `lib/io.uc` + `lib/math.uc` | src-c/Makefile 编译入口 | **不被编译**（独立 0.3.4 工作） |

### §4.2 关键顺序约束（dependency edges）

| edge | 原因 |
|---|---|
| **commit 3 (intrinsic codegen) → commit 7c (移除 sizeof_impl)** | 否则 m0 baseline 回归：旧 `sizeof_impl`/`alignof_impl`/`is_null` 没有 codegen emit 替代 |

### §4.3 不要的顺序（错误示例）

- ❌ 7d（删 memcpy 等）→ 6（加 emit_*_call）：7d 后 `clone_impl` 仍走 builtin 表，新 emit 函数应已存在
- ❌ 8 → 1-7：preprocessor/asm/sys:: 与核心 builtin 完全独立，可并行；但 spec 编排顺序是 last（per 原 plan）
