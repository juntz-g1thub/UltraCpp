## 附录 C. CJK NO-OP 永久决策摘录

> **决策**：UltraCPP 标识符字符集永久限定为 ASCII letters + `_`。非 ASCII 标识符（含 CJK / UTF-8 / emoji 等）永久 NO-OP。
>
> **理由**：
> 1. language design 决策：lexer / parser / symbol table 不引入非 ASCII 路径
> 2. 用户体验：避免双语 spec 中 zh-CN / en 版本标识符语义差异
> 3. 工具链：debugger / IDE / formatter 等周边工具零负担
>
> **覆盖范围**：不进 0.3.5、不进 0.4.0、永远；仅在 spec gap S7 记录为 "permanently not implemented, not implemented in any future version"。
>
> **关联**：
> - spec §2.4 ASCII-only 明文（0.3.5 spec 第一组变更）
> - lexer reject 路径（未来如有需要可加 CI 校验，但不进 0.3.5 范围）
> - 0.3.5 / 0.4.0 / 1.0 release notes 均明示 "CJK identifier support: permanently out of scope, not implemented"
