## §4 版本迭代方案（5 版本）

### §4.1 0.3.4: parser array + struct + lib/print.uc 启动

- **Spec 改动**:
  - §3.5 数组类型（扩展：`T[N]` 声明、长度、初始化）
  - §3.6 结构体类型（扩展：`name: type;` 字段语法）
  - §4.1 运算符优先级（加 postfix `[]` `.`）
  - §4.6 赋值（LHS 可为 struct 字段/数组元素）
  - §11.0.2 UltraCPP stdlib（启动 lib/print.uc first file, per S33 + D2 决策）
  - §12.1 EBNF（加 array_type/array_literal/struct_field_decl/field_access 产生式）
- **m0 flips**: m0_26, m0_27, m0_28, m0_32, m0_33
- **覆盖 S-items**: S12 partial（§3.6 struct 拷贝/移动 syntax）, S33（lib/print.uc first file）
- **Bug fixes 吸收**: m0_34 alloc size bug（codegen.c:1495 hardcoded `malloc(i64 4)` → 计算 sizeof(T)），pre-0.3.4 已部分处理
- **估时**: 4.0 天
- **依赖**: 0.3.3 实施 S27-S32 完成

### §4.2 0.3.5: parser fn-ptr + #include + multi-TU

- **Spec 改动**:
  - §3.4 函数指针类型（扩展形参/调用细节）
  - §9.2 #include 语义（路径解析 + 循环检测）
  - §9.3 #import 新增（模块导入）
  - §9.4 export 声明
  - §12.1 EBNF（function_pointer_type/include_directive/import_declaration/export_declaration 产生式）
- **m0 flips**: m0_37, m0_40, m0_44
- **覆盖 S-items**: S22 partial（§3.4 函数指针作形参）
- **估时**: 2.5 天
- **依赖**: 0.3.4（lib/print.uc 提供 stdlib 工具给 m0_40/#include 测试）

### §4.3 0.3.6: runtime main return + exit

- **Spec 改动**:
  - §6.5 main 函数约定（明确 return N 中 N 是 i32; exit code 取低 8 位）
  - §9.8.1 新增（exit code 8-bit 限制 + trailing `// N` 注释约定）
- **m0 flips**: m0_02, m0_03, m0_08
- **覆盖 S-items**: S9（exit code 8-bit）
- **Bug fixes 吸收**: m0_48 runner regex fix（`run_baseline.sh` extract_expected_exit 对嵌套三元不再 fallback 0；与 trailing-comment 约定同 review 窗口）
- **估时**: 1.5 天
- **依赖**: 0.3.5（m0_44 multi-file 通过，baseline 稳定）

### §4.4 0.3.7: runtime bitwise + string escape + logical

- **Spec 改动**:
  - §2.5 字面量（加 `0b...` 二进制字面量 + 字符串 `\\n` `\\t` `\\\\` `\\"` 转义）
  - §4.4 逻辑运算符（扩 `&&` `||` `!` 完整语义）
  - §4.5 位运算符（`&` `|` `^` `~` `<<` `>>`）
  - §7.6 null 比较（`p == null` 等价 `p == 0`，S15 partial）
  - §7.7 指针算术（单位为 sizeof(T)，S19 partial）
  - §11.1 基本 I/O（明确 `sys::write` wrapper）
- **m0 flips**: m0_05, m0_06, m0_24, m0_25
- **覆盖 S-items**: S15 partial, S17, S19 partial, S22 partial
- **Bug fixes 吸收**: m0_30 deref, m0_36 move（0.3.3 §4.13.5 + §11.0.1 实施后回归检验）
- **估时**: 2.5 天
- **依赖**: 0.3.6

### §4.5 0.3.8: post-M0 spec 清理（5 gaps 合批）+ M0 release

- **Spec 改动**:
  - §3.0 类型转换规则（隐式 widening + 整型提升 + `int*` ↔ `void*`，S26）
  - §4.2.5 副作用与求值顺序（UltraCPP 选 C 风格 unsequenced，S11）
  - §4.6.1 deref-assign 类型安全（S8）
  - §4.8.1 cast 运行时行为（明确 LLVM 指令选择，S14）
  - §6.2 函数调用（void 函数调用只能作 statement，S13）
  - §10.1.1 FFI extern body 来源策略（三选一：libc 链接 / 编译器 stub / 测试 stub，S6）
  - §9.8.2 verify 验证说明（M0 闭合 = 46/46 PASS, m0_07/m0_38 M1-deferred）
  - **§9.8.3 显式声明 S7 resolved by no change**（spec §2.4 保持原状，避免后续 contributor 重新提出）
- **m0 flips**: 无（纯 spec 澄清）
- **覆盖 S-items**: S6, S8, S11, S13, S14, S26
- **估时**: 2.0 天
- **依赖**: 0.3.7（M0 已闭合，纯粹 spec 清理 + release notes）
- **特殊**: 同时是 **M0 final closure release**——0.3.8 release notes 确认 46/46 PASS，标记 M0 → M1 过渡
