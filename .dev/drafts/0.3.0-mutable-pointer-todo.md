# UC_TYPE_MUTABLE_POINTER Cleanup Todo

> **Status**: 待办 / 交给 M1 处理
- **Found by**: test plan review (2026-08-08)
- **Severity**: low (dead code, doesn't affect compilation correctness today)

## 问题

`src-c/include/uc_ast.h:99-100` 包含 0.2.0 spec 残留的类型枚举：

```c
UC_TYPE_POINTER,
UC_TYPE_MUTABLE_POINTER,  // ← 0.2.0 残留
UC_TYPE_REF,
UC_TYPE_ARRAY,
UC_TYPE_FUNCTION,
UC_TYPE_NAMED
```

`UC_TYPE_MUTABLE_POINTER` 对应 0.2.0 spec 的 `T&mut` 类型。**0.3.0 spec 已删除 `T&mut`**（见 `.dev/drafts/0.1.0-borrowck-spec-vs-impl.md` §10-6 / `docs/UltraCPP-v0.3.0-spec-zh-CN.md` §3.3）。

## 影响

- **不影响编译正确性**：parser/lexer 没有触发 `UC_TYPE_MUTABLE_POINTER` 路径（已删除 `&mut` 语法）
- **影响代码整洁度**：AST 枚举含 dead code
- **影响未来修改**：维护者可能误以为这是有效类型

## 处理计划

### M1 期间（推荐）

在 M1 实现 `UC_TYPE_REF` 相关清理时一并处理：

1. `grep` `src-c/` 所有 `UC_TYPE_MUTABLE_POINTER` 引用
2. 删除 AST 枚举中的 `UC_TYPE_MUTABLE_POINTER`
3. 同步删除依赖该枚举的 switch case
4. 确保所有 505 单元测试仍然通过
5. 重新跑 `make -C src-c test` 验证

### 验证

- `grep -rn "UC_TYPE_MUTABLE_POINTER" src-c/` 应返回空
- `make -C src-c test` 仍然 505/505
- `tools/{tokenize,ast,codegen,build}_test.sh` 仍然 5/5 / 7/7
