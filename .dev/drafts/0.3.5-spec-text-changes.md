## §3. 修订明细

### §3.1 §2.4 Identifier Rules 明文补充

**当前**（0.3.4 spec §2.4 隐式 ASCII-only）：

```
letter ::= 'a'..'z' | 'A'..'Z' | '_'
digit  ::= '0'..'9'
```

**新增段**（在 §2.4 末尾追加，zh-CN 语义）：

```
**标识符字符仅限 ASCII 字母与下划线 `_`。非 ASCII 标识符（含 CJK / UTF-8）永久不支持（永久 NO-OP）—— 见 spec gap S7（NO-OP，2026-08-21 user 决策关闭）。**
```

**EN 版相同语义**：

```
**Identifier characters are limited to ASCII letters and `_`.
Non-ASCII identifiers (including CJK / UTF-8) are permanently
out of scope. See spec gap S7 (NO-OP, resolved 2026-08-21 per
user decision).**
```

### §3.2 spec gap S7 状态更新

**S7 原始描述**（per `.dev/drafts/0.3.0-m0-priority.md` §9.x）：

> S7 | §2.4 标识符 | CJK 标识符真支持 | 当前 spec 不要求；走 marker 机制 (`02d7170`) 绕过 | deferred（P1-5） | 未来 spec 修订决定

**S7 终态**：

> S7 | §2.4 标识符 | ~~CJK 标识符真支持~~ | spec §2.4 显式 ASCII-only | **❌ 永久 NO-OP** | ~~未来 spec 修订决定~~（2026-08-21 user 决策关闭）

#### §11.0.2 函数名校正（0.3.5 spec 第二组变更）

0.3.4 spec-en.md:1414 写 `lib/print.uc` 导出函数名 `uc_print`，但 0.3.4 commit 10a (`6d72aa8`) 实际命名为 `uc_print_str`。0.3.5 spec §11.0.2 统一函数名：`uc_print_str`（明确字符串 + `sys::write` 转发）。其他函数名（`uc_print_num`、`uc_print_float`、`uc_alloc`、`uc_free`）与实现一致，无需变更。

> **实测补充（14a 实施后）**：`uc_print` 残留点为 **4 处（zh-CN/en 各 2 处）**，不仅是 0.3.4 spec-en.md:1414。0.3.4 baseline 行号：zh-CN.md:1426+2601, en.md:1414+2545（其中 1426/1414 是 §11.0.2 header 摘要列表，2601/2545 是 §11.0.2 table row）。0.3.5 spec cp 后行号偏移 +2（per §2.4 ASCII-only 段落与 §14 §S7 子节插入），新位置：zh-CN:1428+2603, en:1416+2547 — 已统一替换为 `uc_print_str`。

#### lib/io.uc 处置

`lib/io.uc` 是 0.3.3 之前遗留文件，含旧式 `sys$` 前缀 `print_str`（非 export，**测试夹具**）和 `getValue`（测试夹具）。功能与 lib/print.uc::uc_print_str 重叠。0.3.5 起 **deprecated**（不在 §11.0.2 6 文件清单内，0.3.4 commit 10a 后无引用方）。**计划 0.3.6 commit 删除 lib/io.uc**（与 deprecation 过渡）。

#### 附注：uc_print_num 事实校正（0.3.5 spec 第一组变更补充）

0.3.4-implementation-process.md §7 line 320 写 "`uc_print_num 完整 itoa 实现 DEFERRED 到 0.4.0`" —— 此记录与实际代码不符。commit 10a (`6d72aa8`) 实际导入了完整 itoa（含负数 + 反转），不是 stub。

0.3.5 spec §11.0.2 lib/print.uc 明确：
- `uc_print_str(s: i8*)`: 完整实现（`sys::strlen` + `sys::write(1, s, n)`）
- `uc_print_num(n: int)`: 完整实现（负数 + 16 字节缓冲 + 反转 + `sys::write(1, out, j)`）
- `uc_print_float(f: double)`: STUB（写 `<float>` 字符串，忽略入参 f）；commit 14h (0.3.5) 完整化为简单 ftoa（2 位小数）

**注**：0.3.4 plan / process 中"DEFERRED to 0.4.0"记录系 0.3.4 plan 编写时认知滞后于实际代码（commit 10a 已落地完整 itoa，但 plan 仍按 commit 7d 末态 baseline 假设 uc_print_num 未达完整）。0.3.5 spec 此校正关闭文档不一致。

#### lib/io.uc 不属于 §11.0.2 6 文件清单

`lib/io.uc` 不在 0.3.4 spec §11.0.2 列出的 6 个 stdlib 文件中。0.3.5 spec 明确：lib/io.uc 是 0.3.3 之前的**测试夹具遗留文件**，与 §11.0.2 6 文件清单**无交集**；0.3.4 commit 10a 后 lib/io.uc 无引用方。**0.3.6 commit 删除 lib/io.uc**（cleanup）。
