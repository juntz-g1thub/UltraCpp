## 2. 策略：Hybrid (cp + delta)

### 2.1 为什么 Hybrid？

| 方案 | 优点 | 缺点 | 决策 |
|------|-----|------|------|
| **A. 全量重译（从 zh 重译一遍）** | 与 zh 完全对齐 | ~2700 行未变内容**重新翻译**会引入新错误，浪费 ~6+ 小时 | ❌ 拒绝 |

### Step 3.7 — EBNF 最终状态（决策 #6 落实）

**当前 base §12.1 EBNF 现状**（base = 0.3.2-en，含 stale `unary_expression` 含 `move` `clone` `mod` `unmod` `move_to_thread`）：

> **前提**：决策 #6 要求 en 版按 `.dev/drafts/0.3.3-spec-text-changes.md` §6.2 最终状态写。**不**直接照抄 zh spec §12.1——后者已知 stale（保留 `move` `clone` 在 `unary_expression` 和 `rvalue`）。

**5 个新产生式**（按 spec-text-changes §6.2 完整形态）：

```
// 1. builtin_function_call (NEW)
// 仅含 §11.0.1 的 6 项语言原语: alloc/free/move/clone/mod/unmod
// stdlib 完全移出 (print/strlen/memcpy 等改 import "lib/*.uc")
builtin_function_call
                   ::= 'alloc' '(' type ')'
                    | 'free' '(' expression ')'
                    | 'move' '(' expression ')'
                    | 'clone' '(' expression ')'
                    | 'mod' '(' expression ')'
                    | 'unmod' '(' expression ')'

// 2. intrinsic_call (NEW, per runtime-arch §5.2)
// 4 项: null/is_null/sizeof/alignof, 不进 BUILTIN_SIGS[]
intrinsic_call     ::= 'null' '(' ')'
                    | 'is_null' '(' expression ')'
                    | 'sizeof' '(' type ')'
                    | 'alignof' '(' type ')'

// 3. preprocessor_directive (NEW, §10.2)
// C 风格 @ifdef/@ifndef/@if/@else/@define/@error/@warning
preprocessor_directive
                   ::= '@ifdef' '(' identifier ')' directive_body_list '@end'
                    | '@ifndef' '(' identifier ')' directive_body_list '@end'
                    | '@if' preprocessor_expr directive_body_list '@end'
                    | '@elif' preprocessor_expr
                    | '@else' directive_body_list '@end'
                    | '@define' '(' identifier ',' preprocessor_expr ')'
                    | '@error' '(' string_literal ')'
                    | '@warning' '(' string_literal ')'

// 4. asm_block (NEW, §10.3, GCC 约束风格)
asm_block          ::= 'asm' '{' asm_template '}'
                    | 'asm' 'volatile' '{' asm_template '}'

// 5. qualified_call (NEW, §10.4 sys:: namespace)
qualified_call     ::= identifier '::' identifier '(' argument_list? ')'
```

**修订 `unary_expression` 产生式**：
